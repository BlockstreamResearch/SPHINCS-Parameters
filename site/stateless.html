Scheme

FTS/OTS variant from the report. All ratios compare against the SLH-DSA-128s (SPX) baseline.

Winternitz set

w = {2, 4, 16, 256} is always on (lgw | 8). Extras extend the SPX pool only.

Filter coefficients

Bound each metric as a coefficient of SLH-DSA-128s. Survivors must satisfy every bound.

Importance weights

Higher weight = more important. Each metric's ratio is range-normalised across the surviving pool before scoring.

Filtering funnel

Each filter is applied in sequence. Bars show how many candidates survive each step. All costs are SHA-256 compression calls with the PK.seed block midstate-cached (FIPS 205 SHA-2 layout).

Candidate sieve

Each dot is one (h, d, k, a, w) tuple. Positions are random — the layout carries no meaning. Survivors are coloured by their weighted distance to the origin (blue = closer to ideal, red = farther). Filtered-out candidates fade to grey. The winner is ringed.
